# Configurare gratis, fără API SEO plătit

## Ce primești gratis

Aplicația folosește gratuit:

- Google News RSS România;
- Google News RSS pe categorii cu `when:2h`;
- Google Trends RSS fallback;
- Google Trends Trending Now RSS, dacă îl copiezi manual în `.env`;
- scanare publică oficiuldestiri.ro prin REST public, search public și sitemapuri.

## Ce NU poți primi corect gratis

Nu poți primi garantat, gratuit și automat, numărul exact de căutări Google pentru fiecare subiect. Google Trends este index relativ, nu volum absolut. Pentru volum real/estimativ se folosesc servicii SEO, de obicei plătite.

## Soluția practică fără bani

Folosește scorul de prioritate din dashboard ca înlocuitor editorial pentru volum:

- subiect sub 60: monitorizează;
- 60–74: interes bun;
- 75–84: scrie rapid dacă e neacoperit;
- 85+: prioritate mare / breaking editorial.

În plus, uită-te la:

- câte surse au apărut în ultimele 2 ore;
- dacă trendul este activ / în creștere;
- dacă subiectul este neacoperit pe Oficiu;
- dacă are impact pentru publicul din România.

## Google Keyword Planner gratis

Poți încerca Google Keyword Planner cu un cont Google Ads. Nu este nevoie să cumperi un API separat, dar datele pot fi pe intervale largi, iar accesul/precizia depind de cont și setări. Pentru redacție, folosește-l manual ca verificare secundară, nu ca bază automată a aplicației.
